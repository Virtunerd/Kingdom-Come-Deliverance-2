# Wholesale

**Download:** [wholesale.zip](https://github.com/Virtunerd/Kingdom-Come-Deliverance-2/releases/download/kcd2/wholesale.zip)

Skip the quantity slider: when trading, hold **E** to add an item’s whole stack to the basket, or hold **V** to add every item in that category. At a chest or stash, hold **V** to move a whole category to the other side in one go, with no amount window.

## Installation

ASI files must be dropped manually in `Win64MasterMasterSteamPGO` next to the KCD2.exe. The mod itself goes into `Mods` as usual.

Open the mod folder and drag the asi file to `Bin\Win64MasterMasterSteamPGO\` so it looks like this: `Bin\Win64MasterMasterSteamPGO\wholesale.asi`
