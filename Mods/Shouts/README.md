# Shouts

[Alle Versionen ansehen und herunterladen](https://github.com/Virtunerd/Kingdom-Come-Deliverance-2/tree/main/mods/Shouts)

Beschreibung: Shouts - Battlecry Stops Witnesses - Turn Enemies Into Allies. Ein Rufen-/Kampfsystem, das Zeugen beiseiteführt und Gegner in Verbündete verwandelt.

Lade jede neue ZIP-Version in diesen Ordner hoch. Verwende das Format `Shouts_<Version>.zip`; die Versionsnummer muss mit `mod.manifest` in der ZIP übereinstimmen.

Beispiele: `Shouts_1.0.0.zip`, `Shouts_1.0.1.zip`, `Shouts_1.0.2.zip`.
