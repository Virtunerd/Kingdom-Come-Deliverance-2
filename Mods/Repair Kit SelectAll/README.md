# Repair Kit SelectAll

Tired of pressing E for every single item in the repair kit window? This mod adds a **Select all** button to it.

## Features

- New hint **"A  Select all"** right next to the vanilla hints in the repair kit window
- Press **A** or click the hint to select every item at once
- If everything is already selected, the hint switches to **"Unselect all"** and A deselects everything
- Works with every repair kit (weapon, armour, tailor, cobbler, bowyer, gunsmith), as often as you like, without closing the inventory
- Vanilla rules stay intact: only as many items are selected as the kit's capacity allows
- Same font, same key icons and same style as the vanilla hints, and the hint is fully translated (uses the game's own texts)
- Key A is only active while the repair kit window is open, so it keeps its normal function everywhere else
- Poison windows and all other dialogs stay vanilla

## Compatibility

- Changes Libs/UI/ApseModalDialog.gfx and its UI element definition. Other mods that replace this file will conflict.
- **The Poisoner:** fully compatible. This mod already includes The Poisoner's changes to the same window. Load **Repair Kit Select All after The Poisoner**.
- Works fine without The Poisoner.
- No ASI and no save game changes. Safe to add or remove at any time.

## Installation
Subscribe, or extract the archive into *KingdomComeDeliverance2\Mods*. If you use a mod_order.txt, add *repairkitselectall* (below thepoisoner if you use it).

## Controls

- **A**: select all / unselect all
- **Mouse**: click the "Select all" hint
