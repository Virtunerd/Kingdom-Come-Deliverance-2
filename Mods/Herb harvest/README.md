# Herb harvest

Picking a herb gathers every herb and mushroom type within a large gather radius, each credited as its own item. Edit the cfg for your desired distance.

Requires `herbharvest.asi` in `Bin\Win64MasterMasterSteamPGO` (ASI loader).
