# herbharvest

[Alle Versionen ansehen und herunterladen](https://github.com/Virtunerd/Kingdom-Come-Deliverance-2/tree/main/mods/herbharvest)

Beschreibung: Herb Harvest ASI - Radius for ALL herbs. Vergrößert den Sammelradius für alle Kräuter und lässt diese einfacher erfassen.

Lade jede neue ZIP-Version in diesen Ordner hoch. Verwende das Format `herbharvest_<Version>.zip`; die Versionsnummer muss mit `mod.manifest` in der ZIP übereinstimmen.

Beispiele: `herbharvest_1.0.0.zip`, `herbharvest_1.0.1.zip`, `herbharvest_1.0.2.zip`.
