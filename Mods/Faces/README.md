# Faces

[Alle Versionen ansehen und herunterladen](https://github.com/Virtunerd/Kingdom-Come-Deliverance-2/tree/main/mods/Faces)

Beschreibung: Faces - Change one piece of armor out-of-sight to be undetected again like in Hitmen47. Ermöglicht das Verstecken bzw. Wechseln eines Brust- oder Rüstungsstücks, damit die Tarnung zurückkehrt.

Lade jede neue ZIP-Version in diesen Ordner hoch. Verwende das Format `Faces_<Version>.zip`; die Versionsnummer muss mit `mod.manifest` in der ZIP übereinstimmen.

Beispiele: `Faces_1.0.0.zip`, `Faces_1.0.1.zip`, `Faces_1.0.2.zip`.
