# IronLiver

[Alle Versionen ansehen und herunterladen](https://github.com/Virtunerd/Kingdom-Come-Deliverance-2/tree/main/mods/IronLiver)

Beschreibung: Iron Liver - No Skill - Cap - No Negative Phase. Bietet eine kompensierte/erweiterte Lebens-/Kraftlogik ohne negative Phasen.

Lade jede neue ZIP-Version in diesen Ordner hoch. Verwende das Format `IronLiver_<Version>.zip`; die Versionsnummer muss mit `mod.manifest` in der ZIP übereinstimmen.

Beispiele: `IronLiver_1.0.0.zip`, `IronLiver_1.0.1.zip`, `IronLiver_1.0.2.zip`.
