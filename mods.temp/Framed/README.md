# Framed

[Alle Versionen ansehen und herunterladen](https://github.com/Virtunerd/Kingdom-Come-Deliverance-2/tree/main/mods/Framed)

Beschreibung: Framed - Guards Arrest NPCs For You - Dungeon. Wachen verhaften NPCs oder verhaften them in einer Dungeon-/Gefängnissituation auf Wunsch des Spielers.

Lade jede neue ZIP-Version in diesen Ordner hoch. Verwende das Format `Framed_<Version>.zip`; die Versionsnummer muss mit `mod.manifest` in der ZIP übereinstimmen.

Beispiele: `Framed_1.0.0.zip`, `Framed_1.0.1.zip`, `Framed_1.0.2.zip`.
