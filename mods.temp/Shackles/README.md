# shackles

[Alle Versionen ansehen und herunterladen](https://github.com/Virtunerd/Kingdom-Come-Deliverance-2/tree/main/mods/shackles)

Beschreibung: Shackles - Take Hostages. Greift ein Ziel und nimmt es als Geisel; das System passt zu Dialogen, Skripten und dynamischen Spielaktionen.

Lade jede neue ZIP-Version in diesen Ordner hoch. Verwende das Format `shackles_<Version>.zip`; die Versionsnummer muss mit `mod.manifest` in der ZIP übereinstimmen.

Beispiele: `shackles_1.0.0.zip`, `shackles_1.0.1.zip`, `shackles_1.0.2.zip`.
