# survivalist

[Alle Versionen ansehen und herunterladen](https://github.com/Virtunerd/Kingdom-Come-Deliverance-2/tree/main/mods/survivalist)

Beschreibung: Survivalist - Craft Arrows And Bolts. Ein Survival-System zum Herstellen von Pfeilen und Bolzen und zum erweiterten Überleben im Spiel.

Lade jede neue ZIP-Version in diesen Ordner hoch. Verwende das Format `survivalist_<Version>.zip`; die Versionsnummer muss mit `mod.manifest` in der ZIP übereinstimmen.

Beispiele: `survivalist_1.0.0.zip`, `survivalist_1.0.1.zip`, `survivalist_1.0.2.zip`.
