# Shadowmaker

[Alle Versionen ansehen und herunterladen](https://github.com/Virtunerd/Kingdom-Come-Deliverance-2/tree/main/mods/Shadowmaker)

Beschreibung: Shadowmaker - Shoot-Throw holded-static Flames. Feuer-/Flammenmech und dynamische Wurf-/Schuss-Mechanik mit holded static effects.

Lade jede neue ZIP-Version in diesen Ordner hoch. Verwende das Format `Shadowmaker_<Version>.zip`; die Versionsnummer muss mit `mod.manifest` in der ZIP übereinstimmen.

Beispiele: `Shadowmaker_1.0.0.zip`, `Shadowmaker_1.0.1.zip`, `Shadowmaker_1.0.2.zip`.
