# ThePoisoner

[Alle Versionen ansehen und herunterladen](https://github.com/Virtunerd/Kingdom-Come-Deliverance-2/tree/main/mods/ThePoisoner)

Beschreibung: The Poisoner - Stack Effects. Ermöglicht das Stapeln und Kombinieren von Gift-/Trank-Effekten für stärkere oder neue Effekte im Kampf.

Lade jede neue ZIP-Version in diesen Ordner hoch. Verwende das Format `ThePoisoner_<Version>.zip`; die Versionsnummer muss mit `mod.manifest` in der ZIP übereinstimmen.

Beispiele: `ThePoisoner_1.0.0.zip`, `ThePoisoner_1.0.1.zip`, `ThePoisoner_1.0.2.zip`.
