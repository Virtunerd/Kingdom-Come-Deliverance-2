# argus

[Alle Versionen ansehen und herunterladen](https://github.com/Virtunerd/Kingdom-Come-Deliverance-2/tree/main/mods/argus)

Beschreibung: Argus ist ein simpler Marker-Mod, der ein blau/orange farbiges Punkt-Icon an der rechten Seite der Kompassleiste anzeigt und so den Status von Henry bzw. die Tarnung markiert.

Lade jede neue ZIP-Version in diesen Ordner hoch. Verwende das Format `argus_<Version>.zip`; die Versionsnummer muss mit `mod.manifest` in der ZIP übereinstimmen.

Beispiele: `argus_1.0.0.zip`, `argus_1.0.1.zip`, `argus_1.0.2.zip`.
