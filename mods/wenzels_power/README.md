# wenzels_power

[Alle Versionen ansehen und herunterladen](https://github.com/Virtunerd/Kingdom-Come-Deliverance-2/tree/main/mods/wenzels_power)

Beschreibung: Wenzels Power. Aktiviert alle sichtbaren Perks inklusive modded Perks auf der Perk-Baum-Struktur und erleichtert das Upgraden bzw. das Aktivieren von Fähigkeiten.

Lade jede neue ZIP-Version in diesen Ordner hoch. Verwende das Format `wenzels_power_<Version>.zip`; die Versionsnummer muss mit `mod.manifest` in der ZIP übereinstimmen.

Beispiele: `wenzels_power_1.0.0.zip`, `wenzels_power_1.0.1.zip`, `wenzels_power_1.0.2.zip`.
