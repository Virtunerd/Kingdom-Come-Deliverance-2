# ImmersiveTimeskip

[Release herunterladen](https://github.com/Virtunerd/Kingdom-Come-Deliverance-2/releases/download/kcd2/ImmersiveTimeskip.zip)

Lege ZIP-Versionen dieses Mods in diesem Ordner ab. Verwende das Format `ImmersiveTimeskip-<Version>.zip`; die Versionsnummer muss mit `mod.manifest` in der ZIP übereinstimmen.

Beispiele: `ImmersiveTimeskip-1.0.0.zip`, `ImmersiveTimeskip-1.0.1.zip`, `ImmersiveTimeskip-1.0.2.zip`.
