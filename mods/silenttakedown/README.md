# silenttakedown

[Release herunterladen](https://github.com/Virtunerd/Kingdom-Come-Deliverance-2/releases/download/kcd2/silenttakedown.zip)

Lege ZIP-Versionen dieses Mods in diesem Ordner ab. Verwende das Format `silenttakedown-<Version>.zip`; die Versionsnummer muss mit `mod.manifest` in der ZIP übereinstimmen.

Beispiele: `silenttakedown-1.0.0.zip`, `silenttakedown-1.0.1.zip`, `silenttakedown-1.0.2.zip`.
