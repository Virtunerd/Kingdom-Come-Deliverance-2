# slicer

[Alle Versionen ansehen und herunterladen](https://github.com/Virtunerd/Kingdom-Come-Deliverance-2/tree/main/mods/slicer)

Beschreibung: Slicer. Realer Serienkiller-Mod: Getötete NPCs können geschlachtet und zu Fleisch verarbeitet werden; es gibt Loot-, Verkaufs- und Koch-Mechaniken mit Wegwerfen bzw. Verwertung von Körperteilen.

Lade jede neue ZIP-Version in diesen Ordner hoch. Verwende das Format `slicer_<Version>.zip`; die Versionsnummer muss mit `mod.manifest` in der ZIP übereinstimmen.

Beispiele: `slicer_1.0.0.zip`, `slicer_1.0.1.zip`, `slicer_1.0.2.zip`.
