# doorjammer

[Release herunterladen](https://github.com/Virtunerd/Kingdom-Come-Deliverance-2/releases/download/kcd2/doorjammer.zip)

Lege ZIP-Versionen dieses Mods in diesem Ordner ab. Verwende das Format `doorjammer-<Version>.zip`; die Versionsnummer muss mit `mod.manifest` in der ZIP übereinstimmen.

Beispiele: `doorjammer-1.0.0.zip`, `doorjammer-1.0.1.zip`, `doorjammer-1.0.2.zip`.
