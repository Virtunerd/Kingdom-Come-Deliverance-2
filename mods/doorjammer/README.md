# doorjammer

[Alle Versionen ansehen und herunterladen](https://github.com/Virtunerd/Kingdom-Come-Deliverance-2/tree/main/mods/doorjammer)

Beschreibung: Door Jammer - No One gets in or out. Verhindert das Öffnen oder Betreten durch NPCs bzw. blockiert Türen und Tore in einer bestimmten Situation.

Lade jede neue ZIP-Version in diesen Ordner hoch. Verwende das Format `doorjammer_<Version>.zip`; die Versionsnummer muss mit `mod.manifest` in der ZIP übereinstimmen.

Beispiele: `doorjammer_1.0.0.zip`, `doorjammer_1.0.1.zip`, `doorjammer_1.0.2.zip`.
