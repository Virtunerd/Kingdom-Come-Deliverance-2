# photonoclip

[Release herunterladen](https://github.com/Virtunerd/Kingdom-Come-Deliverance-2/releases/download/kcd2/photonoclip.zip)

Lege ZIP-Versionen dieses Mods in diesem Ordner ab. Verwende das Format `photonoclip-<Version>.zip`; die Versionsnummer muss mit `mod.manifest` in der ZIP übereinstimmen.

Beispiele: `photonoclip-1.0.0.zip`, `photonoclip-1.0.1.zip`, `photonoclip-1.0.2.zip`.
