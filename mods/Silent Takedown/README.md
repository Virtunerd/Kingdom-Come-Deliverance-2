# silenttakedown

[Alle Versionen ansehen und herunterladen](https://github.com/Virtunerd/Kingdom-Come-Deliverance-2/tree/main/mods/silenttakedown)

Beschreibung: Silent takedown. Stealth-Kill und Stealth-KO bleiben lautlos; NPCs hören nichts, egal in welcher Situation die Aktion ausgeführt wird.

Lade jede neue ZIP-Version in diesen Ordner hoch. Verwende das Format `silenttakedown_<Version>.zip`; die Versionsnummer muss mit `mod.manifest` in der ZIP übereinstimmen.

Beispiele: `silenttakedown_1.0.0.zip`, `silenttakedown_1.0.1.zip`, `silenttakedown_1.0.2.zip`.
