# landlord

[Alle Versionen ansehen und herunterladen](https://github.com/Virtunerd/Kingdom-Come-Deliverance-2/tree/main/mods/landlord)

Beschreibung: Landlord. Über 140 passive Einnahmequellen pro Mitternacht, Dialoge, Eigentumsobjekte und mehr; das System sprengt das Standardgeldmodell.

Lade jede neue ZIP-Version in diesen Ordner hoch. Verwende das Format `landlord_<Version>.zip`; die Versionsnummer muss mit `mod.manifest` in der ZIP übereinstimmen.

Beispiele: `landlord_1.0.0.zip`, `landlord_1.0.1.zip`, `landlord_1.0.2.zip`.
