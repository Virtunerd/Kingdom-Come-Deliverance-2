# wakeup

[Alle Versionen ansehen und herunterladen](https://github.com/Virtunerd/Kingdom-Come-Deliverance-2/tree/main/mods/wakeup)

Beschreibung: Wake Up. Keybind H weckt bewusstlose NPCs innerhalb der Reichweite und erlaubt so ein gezieltes Aufwecken bzw. Rückholen aus dem K.O.-Zustand.

Lade jede neue ZIP-Version in diesen Ordner hoch. Verwende das Format `wakeup_<Version>.zip`; die Versionsnummer muss mit `mod.manifest` in der ZIP übereinstimmen.

Beispiele: `wakeup_1.0.0.zip`, `wakeup_1.0.1.zip`, `wakeup_1.0.2.zip`.
