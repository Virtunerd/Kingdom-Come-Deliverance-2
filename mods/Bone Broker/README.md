# bonebroker

[Alle Versionen ansehen und herunterladen](https://github.com/Virtunerd/Kingdom-Come-Deliverance-2/tree/main/mods/bonebroker)

Beschreibung: Bone Broker - Medicus. Kane Walshire kauft Knochen und Schädel und betreibt eine eigene Handelsseite rund um Knochen, Beinknochen, Gebeine und Skelettteile; ein Nebenquest- und Händler-Feature mit Map-Markern.

Lade jede neue ZIP-Version in diesen Ordner hoch. Verwende das Format `bonebroker_<Version>.zip`; die Versionsnummer muss mit `mod.manifest` in der ZIP übereinstimmen.

Beispiele: `bonebroker_1.0.0.zip`, `bonebroker_1.0.1.zip`, `bonebroker_1.0.2.zip`.
