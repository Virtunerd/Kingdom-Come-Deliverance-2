# bulkforge

[Alle Versionen ansehen und herunterladen](https://github.com/Virtunerd/Kingdom-Come-Deliverance-2/tree/main/mods/bulkforge)

Beschreibung: Bulk Forge - Transfer. Überträgt Masseninventar bzw. arbeitet mit größeren Mengen in der Schmiede/Produktion und erleichtert das Kombinieren bzw. Fortschaffen von Gegenständen.

Lade jede neue ZIP-Version in diesen Ordner hoch. Verwende das Format `bulkforge_<Version>.zip`; die Versionsnummer muss mit `mod.manifest` in der ZIP übereinstimmen.

Beispiele: `bulkforge_1.0.0.zip`, `bulkforge_1.0.1.zip`, `bulkforge_1.0.2.zip`.
