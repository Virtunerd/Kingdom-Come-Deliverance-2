# lockbreaker

[Alle Versionen ansehen und herunterladen](https://github.com/Virtunerd/Kingdom-Come-Deliverance-2/tree/main/mods/lockbreaker)

Beschreibung: Lockbreaker. Du kannst vor einer Tür oder Truhe stehen und mit einem Tritt die Sperre brechen, um sie zu öffnen; das HUD zeigt dafür einen passenden Hinweis an.

Lade jede neue ZIP-Version in diesen Ordner hoch. Verwende das Format `lockbreaker_<Version>.zip`; die Versionsnummer muss mit `mod.manifest` in der ZIP übereinstimmen.

Beispiele: `lockbreaker_1.0.0.zip`, `lockbreaker_1.0.1.zip`, `lockbreaker_1.0.2.zip`.
