# shackles

[Release herunterladen](https://github.com/Virtunerd/Kingdom-Come-Deliverance-2/releases/download/kcd2/shackles.zip)

Lege ZIP-Versionen dieses Mods in diesem Ordner ab. Verwende das Format `shackles-<Version>.zip`; die Versionsnummer muss mit `mod.manifest` in der ZIP übereinstimmen.

Beispiele: `shackles-1.0.0.zip`, `shackles-1.0.1.zip`, `shackles-1.0.2.zip`.
