# keepmyweapon

[Release herunterladen](https://github.com/Virtunerd/Kingdom-Come-Deliverance-2/releases/download/kcd2/keepmyweapon.zip)

Lege ZIP-Versionen dieses Mods in diesem Ordner ab. Verwende das Format `keepmyweapon-<Version>.zip`; die Versionsnummer muss mit `mod.manifest` in der ZIP übereinstimmen.

Beispiele: `keepmyweapon-1.0.0.zip`, `keepmyweapon-1.0.1.zip`, `keepmyweapon-1.0.2.zip`.
