# highwayman

[Alle Versionen ansehen und herunterladen](https://github.com/Virtunerd/Kingdom-Come-Deliverance-2/tree/main/mods/highwayman)

Beschreibung: Highwayman. Ermöglicht das Ausrauben von NPCs über Dialoge; Charisma, Stats und Inventar beeinflussen das Ergebnis und verhindern das Erinnern der Tat.

Lade jede neue ZIP-Version in diesen Ordner hoch. Verwende das Format `highwayman_<Version>.zip`; die Versionsnummer muss mit `mod.manifest` in der ZIP übereinstimmen.

Beispiele: `highwayman_1.0.0.zip`, `highwayman_1.0.1.zip`, `highwayman_1.0.2.zip`.
