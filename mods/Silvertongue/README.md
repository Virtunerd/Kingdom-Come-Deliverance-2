# Silvertongue

[Alle Versionen ansehen und herunterladen](https://github.com/Virtunerd/Kingdom-Come-Deliverance-2/tree/main/mods/Silvertongue)

Beschreibung: Silvertongue - Heartbroken to death. Manipuliert offene Welt-NPCs mit dramatischen Lügen, die Charaktere verblüffen, verwirren, aus dem Gleichgewicht bringen und töten können.

Lade jede neue ZIP-Version in diesen Ordner hoch. Verwende das Format `Silvertongue_<Version>.zip`; die Versionsnummer muss mit `mod.manifest` in der ZIP übereinstimmen.

Beispiele: `Silvertongue_1.0.0.zip`, `Silvertongue_1.0.1.zip`, `Silvertongue_1.0.2.zip`.
