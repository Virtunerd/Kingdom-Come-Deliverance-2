# lastknownposition

Lege ZIP-Versionen dieses Mods in diesem Ordner ab. Verwende das Format `lastknownposition-<Version>.zip`; die Versionsnummer muss mit `mod.manifest` in der ZIP übereinstimmen.

Beispiele: `lastknownposition-1.0.0.zip`, `lastknownposition-1.0.1.zip`, `lastknownposition-1.0.2.zip`.
