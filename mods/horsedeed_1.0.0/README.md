Lade jede neue ZIP-Version in diesen Ordner hoch. Verwende das Format `horsedeed_1.0.0_<Version>.zip`; die Versionsnummer muss mit `mod.manifest` in der ZIP übereinstimmen.

Beispiele: `horsedeed_1.0.0_1.0.0.zip`, `horsedeed_1.0.0_1.0.1.zip`, `horsedeed_1.0.0_1.0.2.zip`.
