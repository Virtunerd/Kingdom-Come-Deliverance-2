# AreaHitVials

[Alle Versionen ansehen und herunterladen](https://github.com/Virtunerd/Kingdom-Come-Deliverance-2/tree/main/mods/AreaHitVials)

Beschreibung: Area Hit Vials - Throwable Portion Schnaps Poison - Radial Menu Included. Ein QOL-Mod mit Radial Menu und einem zusätzlichen Wurf-/Gift-Mechanismus.

Lade jede neue ZIP-Version in diesen Ordner hoch. Verwende das Format `AreaHitVials_<Version>.zip`; die Versionsnummer muss mit `mod.manifest` in der ZIP übereinstimmen.

Beispiele: `AreaHitVials_1.0.0.zip`, `AreaHitVials_1.0.1.zip`, `AreaHitVials_1.0.2.zip`.
