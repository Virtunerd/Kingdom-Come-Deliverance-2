Lege ZIP-Versionen dieses Mods in diesem Ordner ab. Verwende das Format `RepairKitSelectAll-<Version>.zip`; die Versionsnummer muss mit `mod.manifest` in der ZIP übereinstimmen.

Beispiele: `RepairKitSelectAll-1.0.0.zip`, `RepairKitSelectAll-1.0.1.zip`, `RepairKitSelectAll-1.0.2.zip`.
