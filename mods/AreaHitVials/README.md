# AreaHitVials

[Alle Versionen ansehen und herunterladen](https://github.com/Virtunerd/Kingdom-Come-Deliverance-2/tree/main/mods/AreaHitVials)

Lade jede neue ZIP-Version in diesen Ordner hoch. Verwende das Format `AreaHitVials_<Version>.zip`; die Versionsnummer muss mit `mod.manifest` in der ZIP übereinstimmen. Ältere Versionen können im Ordner bleiben.

Beispiele: `AreaHitVials_1.0.0.zip`, `AreaHitVials_1.0.1.zip`, `AreaHitVials_1.0.2.zip`.

Der Ordner-Link bleibt gleich. Besucher öffnen ihn und laden die gewünschte Version herunter; für eine neue Version muss kein Link in dieser README geändert werden.
