# AreaHitVials

[Release herunterladen](https://github.com/Virtunerd/Kingdom-Come-Deliverance-2/releases/download/kcd2/AreaHitVials.zip)

Lege ZIP-Versionen dieses Mods in diesem Ordner ab. Verwende das Format `AreaHitVials-<Version>.zip`; die Versionsnummer muss mit `mod.manifest` in der ZIP übereinstimmen.

Beispiele: `AreaHitVials-1.0.0.zip`, `AreaHitVials-1.0.1.zip`, `AreaHitVials-1.0.2.zip`.
