# VirtunerdRadial

[Alle Versionen ansehen und herunterladen](https://github.com/Virtunerd/Kingdom-Come-Deliverance-2/tree/main/mods/VirtunerdRadial)

Beschreibung: Simple VRM - Radial Menu. Ein einfaches Radialmenü für Schnellzugriffe, angepasst an den Stil des Mods und die Bewegungsabläufe in KCD2.

Lade jede neue ZIP-Version in diesen Ordner hoch. Verwende das Format `VirtunerdRadial_<Version>.zip`; die Versionsnummer muss mit `mod.manifest` in der ZIP übereinstimmen.

Beispiele: `VirtunerdRadial_1.0.0.zip`, `VirtunerdRadial_1.0.1.zip`, `VirtunerdRadial_1.0.2.zip`.
