# wholesale

[Release herunterladen](https://github.com/Virtunerd/Kingdom-Come-Deliverance-2/releases/download/kcd2/wholesale.zip)

Lege ZIP-Versionen dieses Mods in diesem Ordner ab. Verwende das Format `wholesale-<Version>.zip`; die Versionsnummer muss mit `mod.manifest` in der ZIP übereinstimmen.

Beispiele: `wholesale-1.0.0.zip`, `wholesale-1.0.1.zip`, `wholesale-1.0.2.zip`.
