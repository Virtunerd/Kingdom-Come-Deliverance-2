# bathmaidchoice

[Alle Versionen ansehen und herunterladen](https://github.com/Virtunerd/Kingdom-Come-Deliverance-2/tree/main/mods/bathmaidchoice)

Beschreibung: Bath Maid Choice - Your maid selector. Wählt die Dienstmagd/Bedienstete per Auswahl aus, statt nur fix vorgegeben auszuwählen.

Lade jede neue ZIP-Version in diesen Ordner hoch. Verwende das Format `bathmaidchoice_<Version>.zip`; die Versionsnummer muss mit `mod.manifest` in der ZIP übereinstimmen.

Beispiele: `bathmaidchoice_1.0.0.zip`, `bathmaidchoice_1.0.1.zip`, `bathmaidchoice_1.0.2.zip`.
