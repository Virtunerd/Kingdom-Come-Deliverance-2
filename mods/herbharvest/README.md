# herbharvest

[Release herunterladen](https://github.com/Virtunerd/Kingdom-Come-Deliverance-2/releases/download/kcd2/herbharvest.zip)

Lege ZIP-Versionen dieses Mods in diesem Ordner ab. Verwende das Format `herbharvest-<Version>.zip`; die Versionsnummer muss mit `mod.manifest` in der ZIP übereinstimmen.

Beispiele: `herbharvest-1.0.0.zip`, `herbharvest-1.0.1.zip`, `herbharvest-1.0.2.zip`.
