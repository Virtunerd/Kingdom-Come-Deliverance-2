# athleticus

[Alle Versionen ansehen und herunterladen](https://github.com/Virtunerd/Kingdom-Come-Deliverance-2/tree/main/mods/athleticus)

Beschreibung: Athleticus - Doublejump - Grabs edges. Ermöglicht Sprünge, Klettern und bessere Bewegung im Gelände.

Lade jede neue ZIP-Version in diesen Ordner hoch. Verwende das Format `athleticus_<Version>.zip`; die Versionsnummer muss mit `mod.manifest` in der ZIP übereinstimmen.

Beispiele: `athleticus_1.0.0.zip`, `athleticus_1.0.1.zip`, `athleticus_1.0.2.zip`.
