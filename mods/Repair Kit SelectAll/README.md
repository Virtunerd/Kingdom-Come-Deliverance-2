# RepairKitSelectAll

[Alle Versionen ansehen und herunterladen](https://github.com/Virtunerd/Kingdom-Come-Deliverance-2/tree/main/mods/RepairKitSelectAll)

Beschreibung: Repair Kit Select All - QOL. Selektiert Reparaturkits und relevantem Zubehör in einem Zug, um das Inventar deutlich schneller zu verwalten.

Lade jede neue ZIP-Version in diesen Ordner hoch. Verwende das Format `RepairKitSelectAll_<Version>.zip`; die Versionsnummer muss mit `mod.manifest` in der ZIP übereinstimmen.

Beispiele: `RepairKitSelectAll_1.0.0.zip`, `RepairKitSelectAll_1.0.1.zip`, `RepairKitSelectAll_1.0.2.zip`.
