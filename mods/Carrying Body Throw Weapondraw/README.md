# Carrying_Body_Throw_Weapondraw

[Alle Versionen ansehen und herunterladen](https://github.com/Virtunerd/Kingdom-Come-Deliverance-2/tree/main/mods/Carrying_Body_Throw_Weapondraw)

Beschreibung: Carrying Body - Throw and Weapondraw. Erlaubt das Tragen eines Leichnams und dessen Werfen, zusätzlich mit Schnellzugriff beim Waffenziehen.

Lade jede neue ZIP-Version in diesen Ordner hoch. Verwende das Format `Carrying_Body_Throw_Weapondraw_<Version>.zip`; die Versionsnummer muss mit `mod.manifest` in der ZIP übereinstimmen.

Beispiele: `Carrying_Body_Throw_Weapondraw_1.0.0.zip`, `Carrying_Body_Throw_Weapondraw_1.0.1.zip`, `Carrying_Body_Throw_Weapondraw_1.0.2.zip`.
