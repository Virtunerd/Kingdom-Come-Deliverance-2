# IronLiver

[Release herunterladen](https://github.com/Virtunerd/Kingdom-Come-Deliverance-2/releases/download/kcd2/IronLiver.zip)

Lege ZIP-Versionen dieses Mods in diesem Ordner ab. Verwende das Format `IronLiver-<Version>.zip`; die Versionsnummer muss mit `mod.manifest` in der ZIP übereinstimmen.

Beispiele: `IronLiver-1.0.0.zip`, `IronLiver-1.0.1.zip`, `IronLiver-1.0.2.zip`.
